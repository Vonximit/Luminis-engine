Tres reglas del motor
regla 01

La página nace con un ADN

Al cargar, el motor genera una personalidad. Cinco valores entre 0 y 1 que definen todo lo que vendrá.

const p = {
  curiosity: rand(),
  calm: rand(),
  elegance: rand(),
  energy: rand(),
  complexity: rand()
};
regla 02

El motor elige, no el diseñador

Ningún color fue hardcodeado. El motor evalúa el ADN mediante scoring y decide tema, velocidad, densidad y espaciado.

scores.neon = energy * 2.2 - calm * 0.8;
scores.glass = calm * 2.2 - energy * 0.8;
// gana el mayor.
regla 03

Los componentes tienen estado

No son estilos. Son comportamientos. Una tarjeta no cambia de color: late, crece, emite luz, vuelve lentamente.

// No escribiste esto:
.card { color: red; }

// Escribiste esto:
card.mood = "important";
// El motor decidió el resto.
